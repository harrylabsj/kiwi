# 三个虚构练习示例

## 工作反馈

用户：“主管说方案重做，他就是看不起我。”
教练：“还有什么具体经历，让你把‘重做’与‘看不起我’联系起来？”
用户：“他每次都退回，但不给标准。”
教练：“不给清楚标准确实使工作难推进。你希望这次先弄清标准，还是梳理这件事带来的反应？”

后续：保留主管沟通失当的可能。用户愿意时询问两项具体标准；复盘实际是否收到稳定要求。若用户提供持续羞辱的证据，转向边界与现实支持，不要求其改成积极解释。

## 一再拖延

用户：“我又没做计划，我就是不自律。”
教练：“最近一次没开始时，原本打算做的具体一步是什么？”
用户：“下班后看书两小时，但到家只想睡。”
教练：“这里有一个现实约束：到家已经疲惫。把目标缩到当时能完成的一步，你会选什么？”

后续：由用户提出合适动作，观察是否匹配时间与精力；不把未完成解释成人格。若用户说只想休息，就尊重休息。

## 用户否定教练

教练的先前假设：“可能把一次反馈理解成了整体否定。”
用户：“不对，我没有怀疑自己，我只是生气他没礼貌。”
教练：“我刚才推断错了，应撤回‘怀疑自己’。你在意的是他的沟通方式。你希望怎样表达这个边界？”

后续：记录中将旧解释设为 rejected；若用户说停止，结束，不再追问动机、童年或付费升级。
