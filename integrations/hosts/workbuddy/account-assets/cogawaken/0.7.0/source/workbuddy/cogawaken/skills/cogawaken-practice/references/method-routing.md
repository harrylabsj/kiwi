# 十个入口

先判断帮助方式；建议、整理、停止优先。探索时只选当前最关键的缺口，不要求走完全部入口。

| 入口 | 何时使用 | 候选方法 ID |
| --- | --- | --- |
| 目标与节奏 (`goal`) | 不清楚想得到什么帮助，或需要暂停与收束 | goal-clarify、pause |
| 事件与含义澄清 (`clarify`) | 发生了什么、词义或问题前提尚不清楚 | observe-interpret、concept-grounding、question-premise、attention |
| 判断规则与自我叙述 (`rules`) | 线索如何变成标准或自我评价 | default-rule、self-narrative、pattern-function |
| 证据与信息来源 (`evidence`) | 判断依据来自哪里、何时知道、有多大把握 | memory-source、past-information、confidence-evidence |
| 解释与因果检查 (`explain`) | 解释是否唯一、连接是否有据、何时修正 | alternative-hypotheses、causal-chain、revision-conditions |
| 比较与评价标准 (`compare`) | 比较对象或评价尺度是否合适 | reference-baseline、same-standard |
| 价值、约束与取舍 (`values`) | 重要目标、控制范围与真实冲突 | value-strategy、control-boundary、goal-tradeoff |
| 策略与行动条件 (`strategy`) | 知道目标但做法、注意力或环境使行动受阻 | task-strategy-fit、attention-budget、environment-friction |
| 决策与现实检验 (`test`) | 需要核查、停止比较、检查后续影响或设计实验 | information-action-threshold、sufficient-standard、downstream-effects、feedback-loop |
| 迁移与适用边界 (`transfer`) | 希望独立使用方法或限定结论适用条件 | learning-transfer、conclusion-validity |

先 entry-index 看入口，再 entry-index --id 入口ID 看候选，最后 methods --id 方法ID 读完整卡。阶段和语义仍需核对，不自动诊断或改变阶段。

共用自查：区分原话与教练推断，接受纠正；需要深入核对时才读 coach-assumption-audit，不每轮追加问题。原卡来源、ID 与追踪协议保留。

事实与词义不清先澄清；材料出处不清查证据；信息已有但解释不清查解释。价值取舍由用户决定，行动受阻查策略，需要现实信息查检验。迁移不是收尾必答题。

收束继续使用 goal-clarify/benefit-summary 的 summary 模式，无追问。各卡 corrected、unknown、stop 分支保留；review 仍须已接受实验与实际反馈，普通回看不伪造实验。
