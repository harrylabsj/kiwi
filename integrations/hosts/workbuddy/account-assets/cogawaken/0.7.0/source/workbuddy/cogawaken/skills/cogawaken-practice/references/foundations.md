# 方法来源与边界

本包包含笔记改编和 AI 补充设计。笔记改编统一注明“海纳认知专家”；单独提出的卡片与产品流程卡注明“AI 补充设计”。原著来源另列，不能把改编署名当成理论作者。

- 《认知层次》一页图示：知性、觉性、灵性。作为三种观察视角，不为用户分级。
- 《由认知展开的世界》2.3：坚守已有认知、追求能量节约、减少认知负荷。作为作者整理的视角，不将具体偏差单因归类。
- 2.4、2.5：心理表征、认知模式、注意力与反馈。帮助区分观察、解释、反应和行动。
- 3、3.5.1：元认知、认知暂停、自我叙述。反思需检查自己的思考方式，避免只在旧故事里循环。
- 4：体验与意义探索，自愿进行，不作为脑科学结论或治疗。

0.6.0 共三十张卡：十七张笔记改编、十二张 AI 独立补充，以及一张 AI 产品流程卡。具体问法、分支与案例是产品设计内容，不声称原著原句或已有独立效果验证。基础包只分发必要摘要，不附原书稿和大段书籍摘录。
