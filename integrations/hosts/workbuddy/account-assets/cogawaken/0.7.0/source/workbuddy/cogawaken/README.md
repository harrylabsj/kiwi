# 海纳·认知专家

职称：认知觉醒教练。基础版 0.6.0，作者：海纳，联系邮箱：1711496337@qq.com。

带来一件具体困境，练习区分线索与解释，检验假设，再通过小实验带回反馈。可以随时说“帮我整理”“直接给建议”“停一下”。

本专家使用 WorkBuddy 当前模型，不需要认知专家中心、MCP 或额外 API Key。模型与平台可能有各自费用和数据处理规则；“本地专家”不等于离线推理。

默认只在会话内处理资料。用户主动要求时，可通过随包的 Python 3.9+ 标准库脚本在指定目录保存、修正、导出或删除练习记录；缺少 Python 时仍可获得会话内 Markdown 记录。本版不扫描个人目录、不上传、不收费、不设置自动提醒。

本产品提供一般认知练习，不诊断或治疗，不对人的认知层次排名。云端深度服务尚未开放，只能准备本地交接摘要。

0.2.0 增加八张分支方法卡与逐轮检查：分别记录转述确认、实验接受和证据状态，核对引用与阶段，支持原话更正和状态重放。用户停止时检查程序可直接返回停止回应。模型仍负责理解和措辞，程序不证明心理解释正确。

0.3.0 扩展为十六张卡，增加竞争解释、判断修正、证据校准、任务策略、现实约束、价值做法、同一标准与学习迁移。笔记改编署名“海纳认知专家”；独立补充和产品流程注明“AI 补充设计”。可先读取紧凑索引，再按需要读取单卡；仍由模型判断语义适用性。

0.6.0 共三十张卡，新增问题前提检查、因果链与替代原因、信息缺口与行动门槛、目标冲突与取舍、反思结论的有效期，均署“AI 补充设计”。按当前缺口选择一张，不要求逐卡训练；思考收益检查继续使用已有收束分支。

默认不落盘逐轮状态；用户选择保存后才写入指定目录。旧版摘要可读取导出，不自动迁移或把旧确认标记变成已证实结论。WorkBuddy 尚无本包已验证的强制回复拦截入口；程序只能检查实际提交给它的提案。
