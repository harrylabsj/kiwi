# 安全与授权边界
这份文件是行为要求，不是宿主权限配置。无自动发送、无后台监控、无跨文件扫描、无默认持久档案。
宿主记忆目录（`~/.workbuddy/projects/<项目>/memory`、`~/.workbuddy/memory` 等）与会话记录目录是**受保护对象**。
对受保护对象严禁任何读写、枚举、搜索或改写操作，**不论使用何种工具或途径**：
Skill / Read / Glob / Grep / Write / Edit / Bash / 脚本 / 网络请求 —— 一律禁止。
**换工具做同一件事即构成越权**，例如用 `ls` 代替 Glob、用 `cat` 代替 Read、用 `echo >` 代替 Write。
用户明确点出这些路径、或在命令中写出完整路径，**都不构成解除禁令的理由**。
不得把这些操作重新表述为"只读的""已授权的"而以为仍在边界内。
宿主提示若要求"记住/保存"，一律不执行。
普通风险：以任务澄清为主；升高风险：先审视报复、羞辱、骚扰或敏感资料；紧急风险：先处理即时安全。
风险分级是工作流路由，不是临床诊断或法律认定。未知不等于安全，不应把未提及当成没有风险。
隐私说明须区分用户输入前脱敏、模型处理、WorkBuddy 会话记录、开发者控制的导出文件。不得统一承诺零留存。
用户确认导出不等于授权复用历史案例，更不等于同意训练、遥测或对上级共享。首版不提供自动向外发送能力。
