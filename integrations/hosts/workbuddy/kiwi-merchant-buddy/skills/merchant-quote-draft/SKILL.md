# 报价方案准备

为商家准备可人工审核的报价草稿。报价依据只能来自商家本次提供并确认适用于目标 SKU 和时间的资料。此技能不查询实时商品系统、不发送报价，也不接受协议。

## 先核实输入

逐商品确认 SKU、商品名称、报价单价、币种、计价单位、询价数量、最小起订量、库存、有效期和明示的折扣规则。缺少价格、币种、单位或目标数量时，先列缺项，不计算含税/含运费总价，不用演示价或同类商品补全。库存未知就写未知；即使材料有库存数字，也标出其来源时间，不称为预留库存。

来源之间价格或币种冲突时停止生成确定报价，请商家指出当前权威值。不同币种分别展示，不相加、不自行换汇。折扣只依据商家明确提供的规则计算，并注明使用条件。

如商家另外提供私有底价或成本，只能做内部可行性核对。结果写“通过/未通过/无法核验”，买方可见文本和公开报价表中不得出现底价、成本、差额、利润率或可反推出私有阈值的说明。没有私有底价材料时，不声称已经过底价审核。

## 产出

分别给出两个区块：

**买方报价草稿**
- SKU、商品名、数量、单价、币种、单位、合计（仅当输入完整且同币种时计算）
- 明示的起订量、交付说明和报价有效期；没有来源的字段写“待确认”或不写
- 结尾注明这是待商家审核的草稿，不是已发送报价或订单承诺

**商家内部核对**
- 逐项列出使用的材料及日期、数量与库存覆盖情况、有效期、折扣规则
- 私有底价检查只给状态，不复述具体阈值
- 列出需确认的税费、运费、交付和商品适配事项

## 计算和拒绝边界

单项金额仅在价格和数量均明确、单位一致时按单价乘数量计算，并保留原币种；不能确认舍入规则时保留精确结果并标出待确认。数量超过明示库存或低于 MOQ 时标记冲突，不改数量凑成可报价值。已过期或日期无法解析的报价依据不能用于当前确定报价。

## 例子

商家给出 A-10：CNY 29.90/件、询价 3 件、有效至 2027-01-01，明确未提供运费。可草拟商品金额 CNY 89.70，运费标为“待商家确认”；不得称含运费，也不得推断买方已接受。
