# Kiwi 报价助理

把商品整理成可导入的表、把价格规则写成可核对的草稿、把名额与公开资料状态讲清楚。

## 0.1.5 相对 0.1.4 的改动

1. **新增「追加发布新商品」能力**（对应工作台「商品与目录发布」页的目录状态列与勾选发布）：
   - 技能新增一节「追加发布新商品（保留原有在售商品）」，把两件事分开讲：**导入仍是整表替换**（要保留原有商品，提交文件里必须原样包含原有全量 + 新增行），**发布是追加语义**（只勾选「未发布」的新增行发布，不影响已发布的商品）。
   - 步骤覆盖：取全量基线 → 追加新增行（原有行逐字保留）→ 核对行数与重复 SKU → 导入预览「移除=0、新增=本次数量」→ 只勾选未发布行、填分类、预览 → 商家本人确认 → 用页首「已发布到目录 N 件」核对。
   - 边界：`状态未知` 不等于 `未发布`，读不到状态时不要发布；页面没有「目录状态」列说明实例版本较旧，请商家先升级，不绕道。
2. **同步商品导入技能到 0.2.0**：以团队候选里的 0.1.3 为基线（补齐 `交易平台/trade_platform` 与 `平台商品ID/platform_product_id` 成对填写、平台限定京东/淘宝/天猫、ID 必须为文本 ASCII 正整数、价格精度不四舍五入等规则），再叠加本次追加发布内容。
3. agent 提示词增加「先分清导入整表替换与发布追加语义」的强制口径。

其余文件与 0.1.4 一致：头像、插件元数据、references/columns.md 未改。
