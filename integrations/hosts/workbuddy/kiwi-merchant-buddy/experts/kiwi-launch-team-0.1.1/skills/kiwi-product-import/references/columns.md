# Kiwi 商品导入列定义（权威）

本文件与 Kiwi 工作台「商品与导入」页的下载模板、以及 Kiwi 仓 `src/cloud/product-import-tabular.ts` 的列定义保持一致；不一致时以后者与工作台模板为准。生成 CSV 时**列名用「中文/字段」双写**（与模板逐字一致），顺序如下：

```csv
商品编号/sku,名称/title,币种/currency,计价单位/unit,单价/price,起订量/moq,库存/stock,供货说明/supply_note,更新时间/updated_at,有效期至/valid_until,状态/status
```

## 列说明

| 列（模板双写） | 必填 | 值格式 | 服务端可识别的常见列名（别名） |
|---|---|---|---|
| 商品编号/sku | 是 | 非空文本，表内唯一 | SKU、sku、货号、商品编号、商品编码、商品sku、item code |
| 名称/title | 是 | 非空文本 | 名称、品名、商品名称、产品名称、商品标题、title、name、product name |
| 币种/currency | 是 | 三字母代码（CNY/USD/EUR/HKD/JPY/GBP…）或中文名（人民币/美元/欧元/港币/日元/英镑，导入时自动转为代码） | 币种、货币、币别、currency |
| 计价单位/unit | 是 | 文本（个/件/箱/kg/套…） | 单位、计价单位、计量单位、价格单位、unit、uom |
| 单价/price | 是 | 正数（元；允许 `1,299.00`、`￥9.9` 等写法，导入时自动清理）；**公开售价** | 单价、价格、销售价、售价、公开价、报价、price、unit price |
| 起订量/moq | 否 | 正整数 | 起订量、最小起订量、起订数量、moq、min order qty |
| 库存/stock | 否 | 非负整数；**不确定就留空，不要填 0** | 库存、库存数量、可用库存、剩余库存、stock、quantity |
| 供货说明/supply_note | 否 | 文本（交期、包装等公开说明） | 供货说明、供货备注、备注、说明、商品说明、描述、description |
| 更新时间/updated_at | 否 | `YYYY-MM-DD` 或 ISO 时间；**留空自动取导入时刻** | 更新时间、数据时间、修改时间、最近更新、updated at |
| 有效期至/valid_until | 是 | `YYYY-MM-DD`（也接受 `2027/12/31`、`2027年12月31日`；Excel 日期单元格可识别）；到期后停止自动报价 | 有效期、有效期至、有效期限、截止日期、到期日、valid until |
| 状态/status | 否 | 在售 / 暂停（也接受 active/paused、1/0）；**留空=在售** | 状态、商品状态、销售状态、上架状态、active |

## 会被整表拒绝的情况（服务端规则，生成文件时就应避免）

- **疑似底价/成本/进价列**：列名含「底价、成本、进价、进货价、采购价、购入价、内部价、cost、floor、base price、purchase price」等 → 整表拒绝，要求删列。
- 必填列缺失（sku/名称/币种/计价单位/单价/有效期至）。
- 单价为空、非数字或 ≤ 0；起订量非正整数；库存非非负整数。
- 日期无法解析（如 `2027-02-30`、`明年春天`）。
- 币种无法识别（如 `火星币`）。
- 同一 SKU 出现多次（错误信息会给出两处行号）。

## 上限

数据行 ≤ 5000，列 ≤ 64，文件 ≤ 4 MiB，单元格 ≤ 2000 字符。超限请分批。

## 整表替换语义

导入是**整表替换**：提交的表生效后，**表里没有的 SKU 会被移除下架**。只想更新部分商品时，其余在售商品也要包含在表里；不想再卖的，直接从表里删除或标「暂停」。
