# Kiwi 开通顾问

陪你走完注册、连接、一键上云、原地升级与上线检查，卡在哪一步就先解决哪一步。

本包用于 Kiwi 商家 Buddy 专用专家，依据 WP25 市场底稿生成。网关不访问商家实例；资料发布、费用和授权由商家本人确认。

首次发布取址入口固定在包内 `skills/kiwi-cloud-deploy/first-publish/`，只含启动脚本和说明，不含商家数据或凭据。云端运行时版本仍由 `cloud-session-cli.mjs stage` 对 npm `latest` 一次解析并验证。

包内嵌入技能标识为 `0.3.5`。这是本专家候选的内嵌副本标记，不代表已创建或发布独立 `0.3.5` 技能资产。

## 0.1.8 相对 0.1.7 的改动

把 2026-11-12 腾讯云工单（202611126202）的答复与当天实测结论写进技能：

1. **新增硬规则 11（发布目标由目录与绑定标记决定）**：平台按「这个目录属于哪个应用」的记录覆盖对应应用；工作区根目录的 `.wbapp_<appId>.genie` 就是这条记录，不得删除、搬移或改 `localDir`，否则发布会新建应用和新域名。
2. **新增硬规则 12（发布后必须核对 appId）**：出现目标 appId 且指向已存在应用才算复用成功；出现 `appId=<none>` 或新应用立即停止上报。
3. **升级流程新增第 8 步（数据目录与备份边界）**：数据目录随实例保留；平台无整包导出；云控制台导出不含实例内目录；禁止运行中拷 SQLite（WAL 一致性）；`/public/v1/updates/snapshot` 实测 422 不可用；拿不到「备份可恢复」证据前不升级。

脚本、`first-publish/` 入口与 `executionAuthorized:false` 门均与 0.1.7 逐字节一致。
