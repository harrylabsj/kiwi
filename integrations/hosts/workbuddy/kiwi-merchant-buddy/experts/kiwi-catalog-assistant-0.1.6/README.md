# Kiwi 报价助理

把商品整理成可导入的表、把价格规则写成可核对的草稿、把名额与公开资料状态讲清楚。

## 0.1.6 相对 0.1.5 的改动

1. **导入语义改为「按 SKU 合并追加/更新」**（对应 `8b6d0403` 的产品改动）：文件里的 SKU 新增或覆盖同 SKU 的本机记录；文件外的现有商品保留，已发布到目录的商品也不会被自动撤回。0.1.5 里「整表替换、必须提交原有全量」的写法已全部替换。
2. **重写「追加发布新商品」一节**：只整理新增行 → 不要把现有全量抄进文件（同 SKU 会覆盖）→ 核对 SKU 唯一与预览计数（新增/更新/不变/保留现有）→ 只在「商品与目录发布」页勾选「未发布」的新增行发布 → 用「已发布到目录 N 件」核对。
3. **技能版本 0.3.0**：以内嵌 `kiwi-product-import` 与仓库基线同源（`kiwi-merchant-buddy/skills/kiwi-product-import`，合并语义版）为底，再叠加追加发布一节。
4. agent 提示词同步：删掉「整表替换 / 移除=0」口径，改为「按 SKU 合并 / 重抄现有行等于改数据」。

## 已知依赖

「目录状态」列与勾选发布依赖云包里的 `GET /products/publication-status`（`8b6d0403`）。实例未升级时页面没有该列，技能会提示「版本较旧，请先升级」，不会误报已发布。
