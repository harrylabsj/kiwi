# 海纳·电商专家 v1.2.0

WorkBuddy 专家包与独立技能共用 `skills/online-shopping-assistant/`。

- 专家“网购助手”：按预算和用途支持购买决策、解释取舍并继续比较。
- 技能“网上购物助手”：根据型号、链接或截图，一次生成规格、价格条件与来源核对表。
- 复用 `kiwi-sourcing` 采购连接器，优先搜索网络商家并推荐符合条件且可核实的商品；用户明确委托时在授权范围内询价、澄清和非绑定还价，连接不可用时如实降级。
- 三种流程：预算选购、指定型号比价、链接/截图核对。
- 新增逐项证据时间、必要费用/总价口径、条件优惠分列与可更新选购清单。
- 不包含后台降价监控、主动通知或账户操作。所有实时能力以宿主工具与来源可访问性为准。

保留插件、Agent和技能标识；作者信息与v1.0.0一致。发布专家包时包含`.codebuddy-plugin/plugin.json`、`agents/`、`avatars/`、`skills/`；独立技能包只包含`online-shopping-assistant/`及其引用文件。
