# 商品可比性与价格规则

## 同款组

同一组必须核实品牌/型号或货号、关键规格、数量、版本、新旧状态、套装内容。颜色、尺码或地区版本影响价格、用途或库存时也必须一致。只有共同缺少的字段不能证明相同；未核实的关键字段标为“待核实”。

| 品类 | 重点核对 |
|---|---|
| 数码 | 容量/内存、代际、网络制式、地区版本、全新/二手/翻新、配件与保修 |
| 家电 | 型号、容量/尺寸、能效与版本、安装费、配送和配件 |
| 鞋服箱包 | 货号、材质、颜色、尺码、单件/组合装 |
| 食品/护肤/日用品 | 净含量、件数、套装内容、可见保质/适用状态 |
| 配件 | 兼容型号、接口/尺寸、数量，是否只售壳/线/替换件 |

不同型号或核心配置属于“同类替代”，按用途解释取舍，不能在同款最低价中混排。同一型号的不同容量可分组展示，不视为等价候选。

可可靠换算的耗材/食品按元/100ml、元/100g或元/件辅助比较，并注明计算数量。赠品、混合套装、计量不清或必要费用不全时不作完整单位成本结论。

## 价格账本

为每个候选区分以下字段，不把它们压成一个没有条件的数字：

- **SKU 标价**：选定具体规格后公开展示的售价；起售价、低至价和未选 SKU 的价格区间只作线索。
- **已确认公开优惠**：当前 SKU 适用、门槛已满足、不依赖未知账户资格的直降/满减。须核对售价是否已含优惠，不能重复扣减。
- **公开比较价**：SKU 标价减去尚未计入且已确认成立的公开优惠。
- **必要费用**：可核实运费、安装费等另列；未知写“未知”，不能按零元。
- **可核实总价**：所有必要费用均明确时，公开比较价加必要费用；否则仅比较公开商品价并说明总价未知。
- **条件优惠**：会员、新人、领券、支付、积分、淘金币、以旧换新、补贴等单列条件。默认不纳入统一公开排序。用户主动提供自己已满足资格的材料时，可另算“基于用户材料的条件价”，标明时效与仍待确认项，不能冒充普遍可得价格。

公开满减必须确认门槛计算基数、SKU适用范围、是否叠加、优惠是否已计入。若必须凑单，不改变用户购物数量来制造更低单价；用户明确愿意凑单时同时展示总支出与所需数量。

只在费用口径一致、规格相同的候选中作价格结论。费用未知或优惠互斥不明确时，不报告确定的最低总价。以人民币金额精确至分计算，最后才四舍五入；不能从“平均省钱”或平台身份推导具体金额。

## 风险与措辞

店铺身份、评分、销量和评论是风险信号，不是正品、质量或售后保证。评论可访问时检查同一 SKU、时间、场景及重复问题；样本不足写“可见样本中出现”，不估算故障率。

允许：“本次核实的同款候选中，A公开商品价较低，但运费未知，尚不能确认最低总价。”

不允许：在范围有限时声称全网最低/历史最低；没有证据声称一定正品、必能领券、必有库存；把配件或低配的低至价当作主商品价格。

## 合成案例：检查规则，不代表真实报价

- A是128GB全新单机，¥299；B是256GB套装，¥279：不同规格，不能推导B是同款更便宜。
- SKU标价¥299，满¥300减¥20：门槛未满足，公开比较价仍为¥299。
- SKU标价¥320，适用满¥300减¥20且尚未扣减，运费¥8：公开比较价¥300，可核实总价¥308。
- 页面已经显示满减后¥300：不能再减¥20。
- A商品价¥300且运费未知，B商品价¥305且运费¥0：可比较商品价，不能断言A总价最低。
