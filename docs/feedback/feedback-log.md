# Kiwi 反馈台账

用途：记录首批商家、Buyer、Host 和协议集成方的可验证反馈，并把反馈转成代码、文档、话术或试点决策。

本文件是结构化模板。真实联系人、邮箱、私聊原文、客户资料、token、底价、精确库存、私有 endpoint 和内部路径不要提交到公开仓库；这些信息留在私有采用账本中。

## 单条反馈记录

建议每条反馈使用一个唯一 ID，例如 `FB-2026-001`，并在当天完成初次分类。

| 字段 | 内容 |
|---|---|
| ID / 日期 |  |
| 来源 | 商家访谈 / Buyer 试用 / Host 集成 / GitHub Issue / 其他 |
| 用户角色 | 商家 / Buyer / Host / 开发者 / 其他 |
| 行业 / 场景 |  |
| 采用漏斗阶段 | 安装 / 初始化 / 商品发布 / Agent Card / 发现 / RFQ / 报价 / 协议 / handoff |
| 用户原话 | 尽量逐字记录；去除个人和商业敏感信息 |
