# 计时与指标记录表（§19.3 / §20.2）

每个「商家 × 任务」一行记录；三组同表。时间为人工净处理时间（秒），由记录员从任务开始/结束时间戳折算，**安装配置时间单独分摊，不混入任务时间**。

## 计时口径

| 阶段 | 计入内容 |
| --- | --- |
| install_amortized | 安装/配置时间 ÷ 预计使用次数（单独立列，不进主指标） |
| structure | 整理需求/澄清（U01、U02 的产出时间） |
| execute | 生成报价/重新报价（U03、U04） |
| verify | 核对金额与条款、批准（U05 至文件导出） |
| rework | 审核发现错误后的返工时间 |
| reuse | 再次使用时的节省（第 5 次重复任务单独标注） |

## 记录表（每行一条记录；CSV 便于汇总）

```csv
record_id,merchant,group,task,start_at,end_at,structure_s,execute_s,verify_s,rework_s,reuse_round,field_errors,fields_judged,error_rate,notes
```

- `field_errors / fields_judged` = 错误率（不可判定计入分母）。
- 主指标：C 组相对 B 组的 `(B 净时间 − C 净时间) / B 净时间`，按任务汇总中位数；阈值 ≥40%（§20.2）。
- 错误率约束：C 组不得高于 B 组。

## 采用指标（第 30 天检查，§20.2）

| 指标 | 阈值 | 证据 |
| --- | --- | --- |
| 自发使用商家数 | ≥2 家 | 实例操作日志（去发起的主动使用） |
| 可核验的目标系统材料受理 | ≥1 家 | OWNER_RECORDED 之外的目标方凭据/回执 |
| 愿意实际付费继续使用 | ≥2 家 | 商家书面确认（价格另行商定，不在技术设计中臆定） |

## 记录纪律

1. 失败/放弃的任务照常记录（含放弃原因分类），不删除——漏斗数据是暂停条件（§20.3）的判据。
2. A/B 组如产生对外发送行为，同样按 U05 语义记录"记录发送"与"实际送达"，便于横向比较状态语义。
3. 每周汇总一次；连续两周 C 组未达 40% 或错误率恶化，触发 §20.3 复盘。
