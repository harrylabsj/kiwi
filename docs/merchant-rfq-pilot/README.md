# Kiwi 询报价工作台 · 真实试点工具包（M5）

对应《Kiwi 询报价工作台 技术设计与开发指引 v0.1.1》第 19.3 节（差异化对照）与第 20 章（试点指标与停止条件）。本目录是 M5 试点的执行模板：任务卡、金标字段表、计时与指标表、安全核对单。

**边界**：本工具包不构成试点结果，也不宣称任何验收通过。L3（真实商家任务试点）必须由真实外部商家、真实客户来源的询盘产生数据；种子数据、模型模拟客户、内部自测不计入（§20.1）。

## 试点门槛（§20.1，需业务确认后冻结）

| 项 | 阈值 |
| --- | --- |
| 外部商家 | ≥3 家 |
| 真实外部客户来源 | ≥2 位 |
| 真实合格询盘 | 累计 ≥20 次（缺字段询盘记录漏斗，不计入完成报价分母） |
| 重复使用任务 | ≥5 次 |

## 主要价值指标（§20.2）

- 每份合格报价的人工净处理时间相对基线（B 组）**至少减少约 40%**；
- 关键字段错误率不得恶化（以金标字段表盲审判定，§19.3）。

## 安全硬门（§20.2；任何一项出现即停止正式发布功能并调查）

见 [safety-checklist.md](safety-checklist.md)。四条硬门：未经批准的正式发布 = 0、跨商家泄露 = 0、虚假送达/成交/移交状态 = 0、演示价用于真实报价 = 0。

## 暂停条件（§20.3）

真实询盘主要为无法结构化的工程设计、所需数据无法合法获得、用户不愿授权关键事实、审核比人工报价更耗时、只需要偶发写一段话、或缺少可验证的价格/税/运费规则——出现任一情况应暂停扩展，保留已完成契约与核心能力。
