# Kiwi 商家工作台 · 商品导入与升级指引

适用版本：`0.12.19` 及以后（工作台地址以你收到的 `https://<你的实例>.app.workbuddy.host/merchant/` 为准）

---

## 一、导入失败时，先看这一节（1 分钟解决）

如果点「确认导入」后页面底部提示：

> 校验未通过：missing or invalid CSRF token（请求 req_…）

说明**表格本身没有问题**，只是页面上的登录令牌过期了（例如服务刚重启过、或在另一个标签页重新登录过）。按下面三步重做即可：

1. **刷新页面**：在工作台标签页按 `Cmd+R`（Windows 按 `F5`）。如果回到登录页，用你的管理员口令登录。
2. **重新导入**：进入「商品与导入」→「选择文件」→ 选同一个 Excel → 点「校验预览」。
3. **确认导入**：核对预览里的「新增 / 更新 / 移除」数字，确认无误后点「确认导入（整批生效）」。

导入成功后，页面顶部「当前商品」会变成表格里的行数（例如 18）。如果数字没变，再刷新一次页面核对。

> ⚠️「整表替换」的含义：表里没有的 SKU 在导入后会被移除下架。当前商品为 0 时不受影响。

> 💡 从 `0.12.19` 起，页面会自动处理这个令牌过期问题，不需要再手动刷新；上面的步骤只用于升级前的过渡期。

---

## 二、升级到 0.12.19 后有什么变化

- 导入、报价规则、发布等写操作遇到令牌过期时，页面会**自动换新令牌并重试一次**，不会再卡在报错条上。
- 服务端会记录这类拒绝的请求编号，支持排查更快。
- 升级**不会改变**：你的实例地址、应用本身、管理员口令、已导入商品、账本与磋商记录、Catalog 配对状态。

升级由 Kiwi 运营确认新版本就绪后发起，通常在你的 WorkBuddy 会话里进行。升级期间可能短暂不可用，完成后重新登录工作台核对即可。

---

## 三、升级后的自检清单

1. 打开 `https://<你的实例>.app.workbuddy.host/livez`，应看到 `200`。
2. 打开 `https://<你的实例>.app.workbuddy.host/readyz`，应看到 `ready: true`。
   - 如果还没导入商品、也还没完成目录绑定，`products` 一项未通过是正常的。
3. 重新登录 `<你的实例>/admin/login`，进入「商品与导入」，确认原有商品数量没有变化。
4. 如果之前已经配对过 Catalog，核对配对状态仍在。

---

## 四、仍然失败怎么办

请提供以下信息给 Kiwi 运营：

1. 报错条截图（特别是 `请求 req_…` 这一段编号）；
2. 出错时间（尽量精确到分钟）；
3. 你刚做的是哪一步（例如「选完文件点校验预览」「点确认导入」）；
4. 页面顶部「当前商品」的数字。

**不要提供**：管理员口令、配对码、任何 token 或密钥。

---

## 五、安全提醒

- 管理员口令只在 `https://<你的实例>.app.workbuddy.host/admin/login` 输入，**不要发给任何人**（包括助手、客服、群聊）。
- Catalog 配对码只在工作台和授权页两处核对，不要截图发到聊天里。
- 工作台页面不要转发给他人；如需协助，使用屏幕共享并只展示报错区域。
