组件归属

三仓各自拥有一种权威。

仓库 / 产品负责什么不负责什么
kiwi买家核心、A2A/KNP、授权、任务、协议、交接与宿主适配不拥有商家商品真相，不执行支付和订单
kiwi-catalog商家身份、验证、新鲜度、商品能力索引和路由不中转磋商消息，不主动抓取商家 ERP
shopping-cli商品、价格、库存、配送、报价政策与商家运营事实不拥有买家预算、宿主记忆或支付权限
协议边界

标准商业能力用 UCP，跨商家询价与磋商用 KNP。

A2A智能体发现、消息与任务承载
KNP询价、报价、还价、澄清与非绑定协议
KTH把协议安全交接到外部成交入口
UCP商品目录、购物车、结账与订单等标准商业原语
KNP 的三个副作用恒为否：不创建订单、不授权支付、不预留库存。
源码与接入

从公开仓库开始。

Kiwi 运行时TypeScript · Apache-2.0

买家核心、协议、商家运行时、MCP 与宿主适配。

 Kiwi 商家发现网络Python · Apache-2.0

验证、索引、路由与商家账户。

 商家商品事实引擎Python · Apache-2.0

商品、库存、政策、询价队列与适配器。

 
# Kiwi 运行时
git clone https://github.com/harrylabsj/kiwi
cd kiwi
npm install
npm run verify

# 商家发现网络
git clone https://github.com/harrylabsj/kiwi-catalog
cd kiwi-catalog
uv sync --locked --extra api --extra dev

# 商家商品事实引擎
git clone https://github.com/harrylabsj/shopping-cli
cd shopping-cli
uv sync --locked --extra api --extra dev
