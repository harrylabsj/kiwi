为什么用 Kiwi Merchant

不是再开一家店，是让 AI 找得到你。

越来越多的采购会从"搜索网页"变成"告诉自己的 AI 智能体"。Kiwi Merchant 让你的企业直接出现在这条新链路里。

你的目录、底价、库存和交易系统仍由你掌控。Kiwi 负责把合适的买家带到你的门前，并把谈妥的条件交回你的结账、ERP、采购单或销售团队。

运作方式

买家 AI 说需求，你的商家智能体接住。

1

被发现

Kiwi Catalog 索引你的公开身份、商品能力、服务区域和可谈判能力。

2

被询价

买家 AI 直接向你的商家智能体发起 RFQ，带来真实数量、交期和条件。

3

按规则报价

底价、折扣、库存和审批由你的商家核心守住；需要人工时进入审核队列。

4

交回你的系统

非绑定协议交给你的结账、ERP、采购单或销售联系人，Kiwi 不替你收款。

数据边界

你的目录，你的城堡。

真实商品事实留在你的系统

Kiwi 读取你授权的公开投影和报价所需事实，不复制你的私有经营数据库。

底价与权限由商家核心守住

低于底价、敏感客户或异常条件，自动进入人工审核，不静默放宽策略。

Kiwi 不碰钱、不创建订单

谈判结果是非绑定协议，最终成交仍在你选择的真实系统里发生。

开始接入

把你的商品接入 AI 采购网络

卖家只需装 Kiwi；shopping-cli 会作为依赖自动带上，kiwi-catalog 由 Kiwi 官方运营、无需自装。先用 CSV / Excel 跑通第一条路径。

# 1. 安装（shopping-cli 会作为依赖自动安装，无需单独装）
npm install -g @harrylabsj/kiwi

# 2. 初始化商家 + 导入商品（CSV / Excel）
kiwi merchant init --merchant-id acme --name "Acme Supply"
shopping-cli --db "$HOME/kiwi-merchant/shopping.sqlite" \
  import-csv-excel --file products.csv --merchant acme

# 3. 发布到网络并保持在线
kiwi merchant publish --shopping-cli-db "$HOME/kiwi-merchant/shopping.sqlite"
kiwi merchant start --catalog https://catalog.kiwi.harrylabsj.com \
  --port 8601 --no-chat

卖家只需装 Kiwi；shopping-cli 作为依赖自动带上，kiwi-catalog 由 Kiwi 官方运营、无需自装。公网部署请使用 HTTPS 与稳定域名。
