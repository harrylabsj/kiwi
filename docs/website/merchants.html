为什么接入

不是再开一家店，是让采购智能体找得到你。

Kiwi 不拿走你的目录、客户和结账。它只让来自不同宿主的采购需求，进入同一个由你掌控的商家状态和政策边界。

1被发现公开身份、商品能力与服务区域进入发现索引
2被询价买家智能体带着真实数量、交期和条件直连
3按规则报价确定性政策守住底价、库存和授权边界
4交回你的系统协议交给结账、ERP、采购单或销售联系人
独立运行原则

宿主或模型离线，商家核心仍然工作。

Hermes、控制台和推理模型都只是可选增强。商家身份、商品事实、询价状态、报价政策、审批、协议和审计始终留在你的商家核心。

确定性报价

常规询价可依据真实价格、库存和政策直接回应。

人工审核

低于底价、敏感客户或异常条件自动进入人工处理。

故障隔离

外部宿主或推理服务故障不阻断询价接收与任务恢复。

安装与使用

先用 CSV / Excel 跑通第一条商家链路。

商家需要 Kiwi 运行时和 shopping-cli 商品事实引擎；官方 Catalog 由 Kiwi 运营，商家无需自行安装。

# 1. 安装商家运行时与商品事实引擎
npm install -g @harrylabsj/kiwi
pip install shopping-cli

# 2. 创建商家并导入商品
export SHOPPING_DB_PATH="$HOME/kiwi-merchant/shopping.sqlite"
shopping-cli --db "$SHOPPING_DB_PATH" merchant create \
  --id acme --name "你的企业" --city 杭州
shopping-cli --db "$SHOPPING_DB_PATH" import-csv-excel \
  --file products.csv --merchant acme

# 3. 创建商家配置
kiwi merchant init --merchant-id acme --name "你的企业"

# 4. 发布公开商品与能力
export KIWI_CATALOG_OWNER_TOKEN_SECRET="由 Kiwi 运营方提供"
kiwi merchant publish \
  --profile "$HOME/.kiwi/kiwi.yaml" \
  --shopping-cli-db "$SHOPPING_DB_PATH"

# 5. 在稳定服务器上保持在线
export KIWI_A2A_PUBLIC_URL="https://merchant.example.com"
export KIWI_A2A_AUTH="bearer:请替换为随机密钥"
kiwi merchant start \
  --profile "$HOME/.kiwi/kiwi.yaml" \
  --catalog "https://catalog.kiwi.harrylabsj.com" \
  --port 8601 --no-chat

公网运行请使用 HTTPS、稳定域名和安全的密钥注入。不要把令牌、成本、底价或私有库存写入公开配置和智能体卡片。
