为什么接入

不是再开一家店，是让采购智能体找得到你。

Kiwi 不拿走你的目录、客户和结账。它只让来自不同宿主的采购需求，进入同一个由你掌控的商家状态和政策边界。

1被发现公开身份、商品能力与服务区域进入发现索引
2被询价买家智能体带着真实数量、交期和条件直连
3按规则报价确定性政策守住底价、库存和授权边界
4交回你的系统协议交给结账、ERP、采购单或销售联系人
独立运行原则

宿主或模型离线，商家核心仍然工作。

Hermes、控制台和推理模型都只是可选增强。商家身份、商品事实、询价状态、报价政策、审批、协议和审计始终留在你的商家核心。

确定性报价

常规询价可依据真实价格、库存和政策直接回应。

人工审核

低于底价、敏感客户或异常条件自动进入人工处理。

故障隔离

外部宿主或推理服务故障不阻断询价接收与任务恢复。

安装与使用

四步，让买家 AI 找到你。

只需安装、初始化、上线、导入并发布。init 之后所有命令无需参数——域名、令牌、商品库都在 init 引导或缺省里。

01
安装 Kiwi

装一个主产品

npm install -g @harrylabsj/kiwi
02
初始化商家

引导填写配置

kiwi merchant init

引导输入商家名称、公网域名与商家令牌（都可回车跳过，稍后补）。自动安装数据引擎。

03
上线

一条命令起服务

kiwi merchant up

自动生成反代配置、启动 Caddy（需先安装）与 A2A 节点，并接入网络。域名 DNS 指向在域名商后台完成。

04
导入并发布

让买家找得到你

kiwi merchant publish \
  --file products.csv

先导入商品再发布名称到发现网络。还没有商品 CSV？下载导入模板 →
