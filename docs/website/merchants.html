不是再开一家店。

QUICKSTART

把你的商品接入 AI 采购网络

先用 CSV / Excel 跑通第一条路径；之后再接 ERP、PIM 或你自己的 API。

01
安装运行时

Kiwi 负责 Agent、协议、策略与交接；shopping-cli 负责商品事实。

02
导入你的商品

用 CSV / Excel 载入 SKU、价格、库存、币种和配送信息。

03
发布并保持在线

生成 Merchant profile，注册到 Catalog，启动你的 A2A endpoint。

04
接收 RFQ

买家 Agent 找到你后，按你的 policy 询价、谈判并交接。

merchant-setup.sh
# 1. 安装（shopping-cli 会作为依赖自动安装，无需单独装）
npm install -g @harrylabsj/kiwi

# 2. 初始化商家 + 导入商品（CSV / Excel）
kiwi merchant init --merchant-id acme --name "Acme Supply"
shopping-cli --db "$HOME/kiwi-merchant/shopping.sqlite" \
  import-csv-excel --file products.csv --merchant acme

# 3. 发布到网络并保持在线
kiwi merchant publish --shopping-cli-db "$HOME/kiwi-merchant/shopping.sqlite"
kiwi merchant start --catalog https://catalog.kiwi.harrylabsj.com \
  --port 8601 --no-chat
↳ 卖家只需装 Kiwi；shopping-cli 作为依赖自动带上，kiwi-catalog 由 Kiwi 官方运营、无需自装。公网部署请使用 HTTPS 与稳定域名。
当前支持：CSV / Excel 首条路径后续：ERP / PIM / 自建 API adapter查看完整部署说明 ↗
