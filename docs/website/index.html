实际流程

从一句采购需求，到你的成交入口。

1提出需求用户继续在自己的智能体里说话
2发现商家按商品、区域、能力与新鲜度路由
3询价与磋商商家智能体基于真实事实和政策回应
4形成非绑定协议接受和交接前必须经过授权门
5交回商家系统结账、采购单、ERP 或销售联系人
诚实边界

谈妥，不等于下单。

Kiwi 止于非绑定商业协议和成交交接。真实订单、付款与库存仍由你信任的系统负责。

不创建订单

协议不会自动变成订单。

不授权支付

Kiwi 不持有资金，也不能替用户付款。

不预留库存

商家系统仍是库存与履约权威。
