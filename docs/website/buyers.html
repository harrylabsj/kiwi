Install

Get Kiwi in one command.

One install. One identity. Start with a sentence.

npm install -g @harrylabsj/kiwi
kiwi buyer init
kiwi buyer search "21.5 inch industrial touch display, IP67"

中文：安装只需要一条命令（发布后；当前未发布时按发布说明）。init 自动创建你的身份，一句需求开始搜索。Buyer 不需要安装其他任何东西、不需要填写任何身份标识。

How it works

Four steps from need to deal.

1

Tell Kiwi what you need

A product, a service, a capability. Plain language is enough.

2

Kiwi shortlists the network

It searches the open network and keeps the merchants that could actually deliver.

3

Agents talk directly

Kiwi inquires, RFQs and negotiates price, MOQ, lead time and customization with each merchant agent.

4

Handoff to the real checkout

When terms are agreed, Kiwi hands you off to the real checkout, PO, ERP or contact — and records exactly what was agreed.

中文：告诉 Kiwi 你要什么 → 它搜索网络筛出真正可能交付的商家 → 直接与每个商家 Agent 询价、谈价格/起订量/交期/定制 → 谈妥后交到真实的结账、采购单、ERP 或联系人，并记录谈妥了什么。

Honest boundaries

What Kiwi shows you is a hint, not a final price.

Prices, stock and delivery are confirmed directly with the merchant before you commit. Kiwi never places an order, authorizes a payment, or reserves inventory on your behalf.

中文：Kiwi 展示的是发现线索，不是最终价格。价格、库存与交期在你承诺前会与商家直接确认。Kiwi 绝不替你下单、授权支付或预留库存。

Who it's for

One consistent way to find suppliers.

For individuals, procurement teams, and buyer agents who want real answers — without trading one marketplace walled garden for another.

中文：面向个人、采购团队与 Buyer Agent——用统一的方式找供应商、拿到真实答复，而不是从一个围墙花园换到另一个。
