用户看到的流程

一句需求，七种高层动作。

找商家→发询价单→查看任务→继续磋商→审批协议→读取协议→成交交接

宿主不需要编排底层协议消息，也不能绕过 Kiwi 与商家的硬策略。

最小披露

商家不需要知道你的全部上下文。

Kiwi 只向远端商家投影完成本次采购所需的商品、数量、交期和授权范围；原始对话、邮件、文件和宿主记忆默认不外传。

权限取交集

宿主许可不能提升用户委托或商家硬策略。

写操作可恢复

任务、审批与协议使用稳定标识和幂等键。

付款永远禁止

Kiwi 只交接成交入口，不执行支付。

参考运行方式

独立命令行仍可用于测试与调试。

产品主路径是宿主内接入；独立命令行保留为参考客户端和回归工具。

npm install -g @harrylabsj/kiwi

# 启动标准 MCP 服务，供 Hermes 或其他宿主连接
kiwi mcp serve \
  --db "$HOME/.kiwi/buyer.sqlite" \
  --principal "buyer:local" \
  --catalog-url "https://catalog.kiwi.harrylabsj.com"

# 参考客户端
kiwi buyer search "200 个 USB-C 扩展坞，7 天内到"

诚实边界：Kiwi 绝不替用户下单、授权支付或预留库存；接受非绑定协议和成交交接必须经过授权门。
